## 客户端行为

所有请求固定访问 `https://api.deepseek.com/`，禁用自动重定向。一次请求最多等待 90 秒，截止时间包含响应正文读取；主动取消与网络超时分开处理。不会自动重试可能已计费的请求。

401、402、429、400/422、404、5xx 分别给出密钥、余额、频率、参数、模型或服务错误提示。不显示远程错误正文和底层异常详情，避免将敏感信息写入会话。异常或空响应明确报错，输出截断时提示内容可能不完整。

普通对话目前每次输出上限为 2048 token；测试问答各为 128 token。非流式 JSON 响应最多读取 4 MiB。现阶段尚无流式逐字显示；本次联调也不代表模型自主工具调用已经实现。

## 在 Windows 上复测

先在“哲里设置 → 哲喵与 DeepSeek”保存自己的密钥并连接获取模型。使用 .NET 10 SDK 和 PowerShell 7，在源码目录运行：

```powershell
# 离线测试：不读取密钥，也不产生网络对话
./scripts/test-deepseek.ps1

# 显式启用真实测试：读取 Windows 凭据，发送两条合成问题，可能产生少量 API 费用
./scripts/test-deepseek.ps1 -Live
```

普通构建和 CI 只执行离线测试。真实测试需显式 `-Live`，没有内置密钥，不自动向 CI 注入本次会话的密钥。测试代码链接生产客户端源码，无另一套复制的请求实现。
