# 哲喵桌宠 · 0.2.2

## 日常操作

| 操作 | 结果 |
| --- | --- |
| 单击角色 | 打开哲喵对话窗口 |
| 按住并拖动 | 移动桌宠；松手后保持在当前屏幕工作区，靠近左右边缘时轻微吸附，不触发对话 |
| 右键或托盘菜单 | 打开对话、哲里设置、移回主屏右下角、隐藏/显示或退出 |
| Ctrl+Alt+Space | 打开对话；快捷键冲突时使用托盘 |
| 隐藏桌宠 | 仅隐藏角色，托盘与快捷键仍可使用；记住隐藏状态 |
| 哲里设置关闭“显示桌面哲喵” | 按全局设置隐藏；从关闭重新开启时解除用户临时隐藏 |
| 同屏应用进入全屏 | 暂时隐藏，离开全屏后按原状态恢复；另一块屏幕全屏不隐藏本屏桌宠 |

## 位置与设置

位置以显示器标识和工作区内的相对坐标记录，所有原生移动使用物理像素。启动、显示器布局变化、DPI 变化和工作区变化后重新约束范围。断开的显示器不再作为恢复目标，改用主屏；也可以从托盘执行“移回主屏右下角”。

状态保存在 `%LOCALAPPDATA%\Zheli\Miao\pet-window.json`，仅桌宠写入，记录位置、用户隐藏状态及最近一次显示/减少动画设置缓存。全局设置仍由哲里设置及 CoreHost 管理，桌宠不会直接修改设置数据库。

设置服务暂时不可用时继续使用缓存；全屏避让的检查独立运行，不等待设置请求。损坏的本地位置文件使用默认位置并提示；未知未来版本的位置文件保留且不覆盖。位置保存失败时提示，当前桌宠仍可使用。

## 动画与资源使用

- 呼吸幅度约 1.5%，尾巴约 ±3°；每隔 4—7 秒轻微眨眼，间隔穿插单侧耳朵动作。
- 使用 WPF 原生动画，目标 30 帧；短动作替换当前时钟，不排队累积。
- 隐藏或拖动时停止动画；“减少动态效果”、系统禁用动画、远程桌面或 WPF 软件渲染等级 0 时保持静态。
- 关闭窗口时停止计时器、取消设置请求、注销热键和托盘。

这是基于现有临时矢量角色的功能实现。用户确定的蓝白猫形象和图标方向不变；最终角色分层素材、正式图标、实际流畅度和资源占用尚未验收。

## Windows 专项验收

1. 在 2560×1600、150% 缩放下，拖到四边后重启，位置可见且不覆盖任务栏。
2. 两块屏幕分别设 100% 和 150%/200%，跨屏拖动后重启；交换显示器相对位置、断开副屏、改变分辨率，确保角色不留在屏幕外。
3. 小幅抖动的单击正常打开；拖动松手、失去鼠标捕获、只在角色上松开鼠标均不得误开对话。
4. 单屏全屏自动隐藏，另一屏全屏不隐藏；隐藏后快捷键和托盘仍可打开对话。
5. 服务离线时仍能隐藏/显示并避让全屏；全局关闭后托盘显示应给出设置入口提示。
6. 减少动态效果即时停止全部动作；静态和隐藏场景检查 CPU/GPU 占用，远程会话检查降级。
7. 重启后隐藏状态保留；从全局关闭改为开启后恢复显示。退出后无残留托盘、计时器或快捷键占用。

已执行的是跨平台位置、手势和保存逻辑测试及 Windows 目标托管编译。以上真实鼠标、DPI、托盘、渲染与多屏场景尚未在 Windows 上执行。

实现参考：[SetWindowPos](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-setwindowpos)、[WM_DPICHANGED](https://learn.microsoft.com/en-us/windows/win32/hidpi/wm-dpichanged)。
