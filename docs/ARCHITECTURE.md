# 架构与接口

## 安装组件所有权

0.2.3 准备三个按用户安装的独立安装器。哲里设置拥有 Settings 与 CoreHost，课表拥有 Timetable 与 Timetable.Host，哲喵拥有 Miao 与 PetHost。课表和哲喵内置设置前置安装器，缺少公共组件时先安装；设置窗口不必常驻。公共目录不使用需要 HKLM 权限的 SharedDLLs 引用计数，依赖通过当前用户安装记录检查。

不同构建的组件禁止混装。安装器使用全应用运行状态 mutex 拒绝运行中的覆盖；设置卸载器在任一依赖应用仍安装时拒绝移除公共组件。安装目录与业务数据分离，卸载不清数据。上述流程尚待 Windows 构建与安装验证。

## 数据所有权

哲里设置是用户可见的统一设置入口，CoreHost 是后台设置所有者。UI 组件以一个 DesignSystem 项目共享，不复制到三个应用，也不通过运行中的设置窗口远程绘制。设置窗口关闭不影响其他软件。

| 所有者 | 数据位置 | 允许调用者 |
| --- | --- | --- |
| CoreHost | Core/settings.db | 所有注册应用可读；设置软件可写、撤销、备份 |
| Timetable.Host | Timetable/timetable.db | 课表维护业务数据；设置软件修改显示偏好和执行备份恢复；哲喵按独立授权使用有限能力 |
| Miao | Miao/miao.db | 哲喵单实例维护会话；其他软件通过唤起转交上下文 |
| Miao | Miao/knowledge.db | 哲喵单实例维护文件索引；CoreHost 保存目录授权，设置窗口不直接读取或修改索引 |
| PetHost | Miao/pet-window.json | 桌宠单实例独占位置、隐藏状态及只读设置缓存文件；不直接修改全局设置或会话数据库 |

同级安装路径、当前 Windows 用户、命名管道服务端/客户端 PID 和程序路径共同限定接口调用者。协议版本为 1，消息最大 4 MiB，请求编号为 UUID。未知方法或不匹配调用方拒绝。当前没有基于发行签名的身份认证，不能抵御能够以同一用户权限替换安装目录程序的攻击者。

管道建立失败可拉起后台所有者；已经发出的写请求不自动重试。业务保存使用预期 revision，数据库会拒绝覆盖较新数据。相同请求编号和内容可获得原操作回执，不重复修改；相同编号不同内容拒绝。当前只撤销最后一次仍未被其他修改覆盖的操作。

## 课表规则

- Course 保存名称、默认教师、颜色和备注；Arrangement 保存可版本化的上课安排。
- 每个 ArrangementRevision 有生效范围、星期、节次、周次集合及教室。单双周在输入阶段转换为明确周次，不另存容易冲突的规则字符串。
- 单次实例键固定为 ArrangementId + SourceWeek。跨周调课改变目标日期，不改变实例键，不再生成第二份实体课程。
- 单次变动保存原安排与覆盖信息。正常重复安排不会在实际开学前生成，但手动临时课可以。
- 重复安排从指定周修改时截断旧版本的未来区间；保留已有覆盖。若变更导致覆盖失去对应原实例，保存失败，要求用户先处理。
- 作息按学期内生效周选择，课程只引用节次。新作息节数不足或覆盖后的节次无效时拒绝保存。
- 冲突以目标日期的真实起止时间判定，停课不占时间；允许用户明确保留冲突。

## 关键接口

| 方法 | 调用方与作用 |
| --- | --- |
| settings.read/save/undo/history/backup | 配置读取与设置软件维护 |
| timetable.read/save | 课表快照查询与带版本的事务保存 |
| timetable.preferences | 设置软件修改周末、教师显示 |
| timetable.query | 哲喵获授权后查询最多 32 天课程摘要 |
| timetable.prepare | 哲喵对明确实例预计算 move/cancel/restore，返回对比、冲突、3 分钟有效 token |
| timetable.commit | 再次检查授权，用 token 捕获的 revision 保存；过期或已变更时拒绝 |
| timetable.miaoUndo | 只允许撤销哲喵发起且仍为最新的操作 |
| timetable.undo/history/backup | 课表操作与本机一致性快照 |
| timetable.exportBackup/restoreBackup | 设置软件导出、验证并恢复密码加密备份 |

接口实现位于 `Contracts/Protocol.cs`、两个 Host 的 `Program.cs`。新增软件应新增能力与调用方注册，不得取得其他软件的数据库写权限。

## DeepSeek 与文件边界

密钥由 Windows Credential Manager 保存，不出现在设置数据和备份中。模型通过 `/models` 获取，聊天使用 `/chat/completions`，禁止 HTTP 重定向。当前仅非流式文本响应，提供取消；未集成模型工具调用。

课表查询结果与文件摘录标记为 LocalOnly，不进入后续云端对话历史。发送课程摘要必须全局授权、本次勾选、预览确认，并在实际发送前重新检查授权。当前自动化写操作来自用户明确按钮，模型不能直接提交任意 JSON 修改数据。

文件知识库授权保存在统一设置中，读取与云端发送分离。私密目录禁止外发，即使其父目录允许发送；关闭该私密目录的本地索引也不会解除私密限制，移除该授权项时会明确提示规则变化。

`DocumentTextExtractor` 只读解析 TXT、Markdown、PDF、DOCX、XLSX、PPTX。PDF 采用 PdfPig；OOXML 使用受限 ZIP/XML 读取，不运行 Office、宏、公式或外部关系。Word定位使用段落号，Excel原值与公式缓存值明确标记，PPT根据presentation关系顺序定位。

`KnowledgeIndex` 使用独立 SQLite 文件/片段表。文件级事务替换索引；后台以大小和修改时间筛选变化，用户搜索及云端发送前用 SHA-256 检查内容。撤销授权、无法确认读取、源文件删除或解析失败时清理对应片段，不返回旧内容冒充最新结果。索引是缓存，可重建；既有会话中本地摘录不会随清理索引删除。

每次发送只包含明确勾选的1—6个片段及相对文件名、位置，不包含整个文件或绝对目录。资料按不可信数据传给模型，模型没有执行文件指令或修改文件的工具。回答列出所用参考来源，不保证模型的每个引用都准确，仍需核对原文。

文件大小、解压大小、页数、片段与总索引容量均设上限，拒绝DTD和重解析点。路径检查不是防御同用户恶意并发替换文件的完整沙箱，未来需独立工作进程、句柄约束与硬超时；当前取消在文件/页面/片段之间检查，不能强制中断解析器内部正在处理的页。

## 备份格式

`.zhelibackup` 是 `ZHELIBK1` 魔数、长度、版本化头、16 字节认证标签和加密 SQLite 快照。使用随机盐、随机 nonce、PBKDF2-SHA256（600000 次）派生 256 位密钥，AES-GCM 验证头及正文。当前最大快照 64 MiB。

恢复先验证认证标签和 SQLite 完整性，再读取领域数据、验证规则并通过所有者事务导入。备份包含源快照内的操作记录，但恢复行为只导入业务数据，不把旧日志覆盖到当前操作日志。恢复前保存的本机快照未加密，存于同一用户数据目录。

版本号 1 数据库当前没有从既往正式版本迁移的承诺。检测到未来 schema 必须拒绝打开；正式发行前应建立迁移测试及恢复演练。
