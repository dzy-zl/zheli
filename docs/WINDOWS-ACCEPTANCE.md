1. PowerShell 7 运行 `scripts/build-windows.ps1`，核心测试预期 96 项通过，独立 DeepSeek 离线测试预期 28 项通过，全部应用正常生成资源与发布。

3. 按 INSTALLER-BUILD.md 生成安装器。单独运行 Timetable 安装器应自动安装设置公共组件，不安装哲喵时课表完整使用。再安装相同构建 Miao 安装器，共享组件应复用，不覆盖已有数据。检查开始菜单及三个独立卸载记录。
4. 反复启动三个应用，应只唤起各自原窗口；哲喵已有会话时从课表进入，应接收新的可见上下文。回答期间收到上下文不能悄然改变正在发送的内容。
5. 运行中安装/卸载应明确拒绝。关闭所有程序及 CoreHost/Timetable.Host/PetHost 后，先尝试卸载设置，应因其他应用依赖而拒绝；卸载课表后哲喵仍可用，最后依次卸载哲喵、设置。程序移除，业务数据、备份保留。不同构建覆盖应拒绝，同构建重装应保留数据。使用新安装器时不运行旧便携卸载脚本。

## 界面与无障碍

- 主分辨率下检查 7 天、全部节次、长课程名、备注、多冲突卡片。任何关键状态必须有文字，不能仅看颜色。
- 缩小到 1000×700、760×600，再放大；详情应在窄屏覆盖、宽屏占右栏，搜索文本框不能每输入一个字失焦。
- 滚动时表头与节次固定；一分钟刷新不能把用户滚动位置跳回顶部。
- 连续快速切换 20 次周次，最后停在目标周，动画不能排队，工具栏与日期框架尽量稳定。
- 明暗主题、系统主题切换、玻璃滑杆、减少透明度、字号 150%、减少动态效果；三个应用在 2 秒内同步。
- 检查玻璃单层 1px 描边四边等宽，今天列和时间线不覆盖文字；精确材质与最终动画仍需迭代。
- Windows 高对比度与 Narrator：按钮读名、键盘焦点、弹窗、Esc、Ctrl+F、Ctrl+N；输入框内操作不误切周。
- 窗口最大化/还原、切换 100%/150%/200% 显示器和断开副显示器后重启。当前窗口恢复需重点检查最大化后的正常尺寸。

## 哲喵、权限和网络

- 未授权课表查询时查询失败；只读授权不能写；撤销写权限后，已经生成的确认方案也不能提交。
- 未设置密钥/模型时有清楚引导；错误密钥、断网、429、超时和取消均不显示虚假的成功。
- 运行 `scripts/test-deepseek.ps1 -Live` 验证 Windows 凭据与 `/models`、聊天的集成；Linux 上已通过的客户端合成问答不能代替这一项。敏感课表摘要默认不发送；本次勾选后应预览并确认；确认中撤销发送权限应阻止发送。
- 在设置中授权目录，测试重开后保留，哲喵关闭时不执行后台索引；启动后增量更新，搜索前核对内容。
- 测试PDF页码、DOCX段落、XLSX工作表和单元格、PPTX幻灯片顺序；扫描页、损坏文件与超限文件须提示识别不完整。
- 源文件删除或改名后旧结果不再出现。撤销本地读取后对应索引清理；符号链接/联接、无权限目录和过大文件不可越权读取。
- 父目录允许发送、子目录标记私密时，子目录片段仍不能发送。确认界面打开期间撤销权限或改动来源文件，发送应拒绝，要求重新检索。
- 一次仅发明确勾选的1—6个片段；旧会话摘录和根据片段生成的回答不得在后续默认聊天历史中再次外发。停止检索后应恢复可操作状态。
- 桌宠专项按 `docs/PET-DESKTOP.md` 验收：拖动不触发聊天、位置与隐藏状态记忆、不同 DPI 跨屏、副屏断开、同屏全屏避让、静态降级、退出释放资源。
- 关闭课表窗口后，哲喵仍可通过课表后台查询；没有安装课表组件时应明确提示缺少组件。

## 备份与故障

- 导出后重开三应用仍能读取。错误密码、修改备份一字节、错误所属应用、已有非空同名文件均拒绝。
- 恢复显示替换提示，先生成保护快照；恢复完成刷新课表可见。恢复前后设置与密钥不应意外改变。
- Windows 临时备份文件必须可以删除，目录内不残留解密快照。明确本机保护快照本身未加密。
- 磁盘满、只读目录、进程中断、服务突然退出和损坏数据库需要专项注入测试；当前未覆盖，正式发行前不能省略。
