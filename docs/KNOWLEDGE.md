# 哲喵文件知识库 · 0.2.0

这一版提供真实本地检索和用户确认后的片段问答。它是关键词检索，不是语义搜索，不会把所有电脑文件交给模型。

## 使用步骤

1. 打开哲里设置 → 文件知识库，点击“添加文件夹”，确认授权。目录及子目录内的支持文件会进入本地索引。
2. 只在本地查资料时，保留云端发送关闭。可以把某个目录设为“私密目录”；即使父目录允许发送，这个目录内也不能发送。
3. 打开哲喵 → 本地文件搜索，输入关键词。结果显示相对文件路径、准确可获得的位置和摘要；“查看检索来源”可以打开所在文件夹。
4. 如果需要AI回答，先在设置单独允许该目录发送，切换DeepSeek对话，输入问题并勾选本次文件片段。预览中逐条勾选最多6个片段，确认后才发送。
5. 文件已改动或权限已撤销时，发送会被拒绝。重新搜索核对后再选择，不会默默发送旧版本。

## 格式与位置

| 格式 | 提取位置 | 当前限制 |
| --- | --- | --- |
| TXT / Markdown | 行号 | UTF-8或带BOM的Unicode编码；不是Markdown渲染结果 |
| PDF | 页码 | 仅文字层；扫描页、图片、复杂阅读顺序未完整处理 |
| DOCX | 正文段落号 | 包含表格中的段落；不虚构页码，不含页眉页脚、批注和图像 |
| XLSX | 工作表名＋单元格地址 | 保存的原始值/公式缓存值，不重新计算，日期格式、合并单元格等显示语义未完整还原；隐藏工作表明确标记 |
| PPTX | 实际幻灯片顺序 | 正文文本；不提取图片和演讲者备注 |

旧二进制 DOC/XLS/PPT、图片和 OCR 尚不支持。没有匹配结果不代表未识别内容里不存在相关信息。

## 更新与撤销授权

哲喵窗口运行期间每分钟检查一次文件变化；后台快速检查采用修改时间与大小，用户检索前再核对内容哈希。关闭哲喵后不会继续索引，桌宠本身不负责解析文件。

停用或移除授权后，哲喵下一次刷新会清理该授权对应的缓存。索引不存在于设置数据库，原文件不会被修改。过去已经保存的本地会话摘要保留，且仍标记为不随云端历史发送。清理缓存是逻辑删除，不承诺磁盘取证不可恢复。

关闭某个目录读取，会同时阻止其他授权目录读取它；例如关闭子目录，父目录也不能继续索引子目录内容。私密子目录设置即使停用读取仍然阻止父目录发送。移除该目录条目会使父目录规则重新适用，移除时有明确提示。

## 性能与安全边界

目前最多24个授权根目录，一次扫描最多5000个文件，递归20层；每个文件32MB、PDF/PPT最多500页、解压总量128MB、单XML部件16MB、每文档200万字符、总索引4000万字符。达到限制会给出说明，不能把不完整扫描当成全目录检索成功。

每次最多显示30条匹配结果。每个候选摘录最多600字符，发送最多6条，保留文件和位置。模型收到参考来源列表，但它对来源的解读仍可能出错，界面提示核对原文。

解析不执行宏、公式、外部关系或DTD，不自动跟随链接目录。当前解析器运行在哲喵进程内，仍需在后续版本增加独立进程、硬超时和更严格的文件句柄隔离。大文档处理期间可点击“停止”；底层解析某页时可能不能立即响应。

文件知识库数据库当前不加密；不包含在课表备份中，可从源文件重建。没有开放文件移动、重命名、删除或覆盖能力。
