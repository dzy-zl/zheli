# 实现与验收状态

日期：2026-09-23。版本：0.2.3 开发版。这里的“已实现”指源码包含真实功能，不代表 Windows 上已验证可用。

0.2.3 已生成三个未签名测试版安装包。Windows Server 2025 runner 上 96 项核心、28 项离线客户端、19 项打包检查通过；六个程序原生发布、Inno 编译、三个窗口启动、桌宠存活及安装卸载流程通过。详见 `verification/windows-ci.json`，运行编号 35932215812。仍非正式发行版本。

0.2.2 新增桌宠位置/隐藏记忆、物理像素跨屏恢复、拖动手势、眨眼/耳朵/尾巴动作、按显示器避让全屏与静态降级；新增 20 项核心逻辑测试，真实 Windows 动画与鼠标交互待验收。

0.2.1 已用生产客户端完成真实 DeepSeek 模型发现、合成课表问答与文件引用问答；新增 28 项离线客户端测试。未读取用户个人文件或真实课表，密钥不入包。详见 `docs/DEEPSEEK-TESTING.md`。

## 0.2.3 验证边界

- Linux 准备阶段 20 项脚本/合成检查通过，Windows 对应为 19 项；另有 96 项核心和 28 项客户端测试实际在 Windows 执行通过。
- Windows CI 已完整执行原生资源发布、Inno 编译、三应用窗口启动、桌宠进程存活、同构建重装、跨构建拒绝、依赖保护、共存卸载和数据文件保留检查。
- 修复了类库错误启用独立部署、编译器版本识别及缺少 App.xaml 资源初始化导致的启动崩溃。原始失败日志与最终通过记录均保留在 GitHub Actions。
- 只验证短时间启动及指定流程，未完成 Windows 11、150% DPI、长时间运行、完整业务/故障恢复和最终视觉验收；未签名。
